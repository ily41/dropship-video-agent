# CapCut method (how the agent builds CapCut projects)

The agent uses the community CapCut MCP server (https://github.com/JmsLdrn/capcut-mcp), registered in
Claude Code as `capcut`, with the text template project `TEXT_STYLE`. The full rules are in CLAUDE.md
under "CAPCUT MERGE". Add your own extra CapCut rules below this line - the agent follows them.
